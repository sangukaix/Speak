# Roadmap

## MVP

- Complete Phases 0-5: reliable foundation, UI, authentication, profile, and text tutor.
- Add lesson session and a basic structured report after the text flow is stable.
- Validate learner value before investing in advanced media or agent orchestration.

## Beta

- Add OpenAI Realtime, WebRTC voice, transcripts, lesson history, and learning memory.
- Pilot personalized next lessons and pronunciation evaluation.
- Add observability, data retention controls, and staged mobile distribution.

## Production

- Harden privacy, abuse protection, cost controls, backups, and operational monitoring.
- Add subscriptions, notifications, administration, analytics, and store releases.
- Introduce specialist agents and an avatar only where evaluation shows a measurable benefit.
